29. Semantic Element: is an element that clearly describes its meaning to both the browser and the developer.

    -> Semantic <nav> : <nav> element is a semantic tag introduced in HTML5. It represents a section of a page whose purpose is to provide navigation links , This enhances code readability and understanding.

    -> Semantic <secton> : is used to group together a related block of generic content within an HTML document. It represents a standalone section of content, typically with a heading, that is thematically grouped.

    -> Semantic <article>: represents a self-contained composition in a document, page, application, or site.

    -> Semantic <aside>: represents a portion of a document whose content is only indirectly related to the document's main content. Asides are frequently presented as sidebars or call-out boxes.
